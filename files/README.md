# Portfolio

A fast, dependency-free portfolio. No build step, no framework.

## Customise
Edit **`data.js`**: name, bio, stats, experience, projects, achievements, skills, contact, social links.
Add your photo (e.g. `assets/me.jpg`) and `resume.pdf` next to `index.html`.

## Run locally
Open `index.html` in a browser, or run `python -m http.server`.

## Deploy on GitHub Pages
1. Create a repo named `yourusername.github.io`
2. Push these files to the `main` branch
3. Settings → Pages → Source: `main` / root
